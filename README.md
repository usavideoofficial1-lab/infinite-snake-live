# 🐍 Auto Snake 24/7 — Endless AI Growth Game

A fully autonomous, self-playing Snake game specifically designed for **24-hour continuous YouTube Live streaming**. 

## ✨ Features
- **Autonomous Gameplay:** Uses BFS (Breadth-First Search) pathfinding to find food and avoid self-collision.
- **Infinite Levels:** Level progression never stops. Speed and difficulty increase gradually.
- **Self-Healing AI:** If the snake gets trapped, it automatically recovers without stopping the live stream.
- **Procedural Sound Effects:** Built-in Web Audio API for keyboard click and eating sounds.
- **Live Stream UI:** Beautiful 9:16 vertical layout with real-time stats.

## 🛠️ Tech Stack
- **Frontend:** HTML5 Canvas, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Audio:** Web Audio API

## 🚀 How to Run
1. Open terminal in this folder.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000` in your browser.
